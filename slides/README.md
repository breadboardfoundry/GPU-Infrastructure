A Slidev presentation for the "Sustainable AI: Pandoro presentation with Keenan Johnson" event.

**Event Details:**
- Date: Thursday, January 22, 2026 at 12:00 PM PST
- Format: Online event (~1 hour with Q&A)
- Host: Pascal Joly

## Quick Start

### Option 1: Using npm

```bash
npm install
npm run dev
```

### Option 2: Direct with Slidev CLI

```bash
npx slidev
```

The presentation will open at `http://localhost:3030`

## Useful Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server with hot reload |
| `npm run build` | Build static SPA for hosting |
| `npm run export` | Export slides to PNG images |
| `npm run export-pdf` | Export slides to PDF |

## Presenter Mode

Press `P` during the presentation or navigate to `http://localhost:3030/presenter` to access presenter mode with notes and timer.

## Keyboard Shortcuts

- `Space` / `→` / `↓` - Next slide
- `←` / `↑` - Previous slide
- `o` - Toggle overview mode
- `d` - Toggle dark mode
- `f` - Toggle fullscreen

## Customization

Edit `slides.md` to modify the presentation content. Slidev supports:
- Markdown syntax
- Vue components
- UnoCSS utilities
- Mermaid diagrams
- Code highlighting
